## 📌 Project Architecture
This project demonstrates virtual IoT prototyping by connecting a simulated hardware board in **PICSimLab** with real-world **Blynk IoT** cloud infrastructure over Ethernet:
- **Climate Control:** Reads ambient temperature from analog LM35 sensor to dynamically adjust PWM cooling fan speed.
- **Automated Lighting:** LDR analog sensor monitoring ambient light levels to automatically regulate interior illumination.
- **Remote Mobile Overrides:** Bi-directional telemetry allowing manual appliance switching and threshold configuration via the Blynk mobile dashboard.

---

## 🛠️ Simulation & Tools
- **Simulator:** PICSimLab (Board: Arduino Uno / PICGenios)
- **Ethernet Module:** Virtual W5500 SPI Ethernet Shield
- **Cloud Service:** Blynk IoT Platform (Virtual Pins V0 – V4)
- **IDE:** Arduino IDE with Blynk C++ libraries
