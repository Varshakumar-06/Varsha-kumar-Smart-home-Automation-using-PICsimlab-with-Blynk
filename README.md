# Varsha-kumar-Smart-home-Automation-using-PICsimlab-with-Blynk
Smart Home Automation using PICSimLab and Blynk simulates IoT control through virtual components. Using Arduino IDE and Ethernet Shield (W5500), sensors like LDR and temperature manage lights, fan, and heater. Blynk app allows remote monitoring and control, showing real-time sensor data via internet.
